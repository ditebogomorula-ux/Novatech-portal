# Novatech-portal

Static NovaTech Service Operations portal scaffold.

Structure:
- index.html — Home
- submit-ticket.html — Submit Ticket (mock form placeholder)
- knowledge-base.html — FAQs & downloads
- team.html — Team roster
- dashboard.html — Sample dashboard

Notes:
- Logo currently uses assets/novatech-badge.svg. Replace with your original image by uploading it to assets/original-logo.png (or .svg) and editing the <img> src in the HTML files.
- To enable real form submissions, provide a Microsoft Forms or Google Forms link and I will embed it on submit-ticket.html.
