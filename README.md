# Novatech-portal

This repository contains a static HTML/CSS scaffold for the NovaTech Service Operations Portal.

Pages included:
- index.html — Home
- submit-ticket.html — Embed for Microsoft Form and technician guidance
- knowledge-base.html — FAQs and download links
- team.html — Team roster and roles
- dashboard.html — Links to the provided Excel workbook and sample metrics

How to deploy on GitHub Pages (quick):
1. Go to the repository Settings → Pages.
2. Under "Source", select the branch `main` and the folder `/ (root)`, then click Save.
3. After a minute the site should be available at: `https://ditebogomorula-ux.github.io/Novatech-portal/`.

Replace assets/logo.svg with your real logo file or update the path in the HTML.

To replace the sample metrics on the Dashboard with a live embed, provide a Power BI or OneDrive embed link and I will add it to dashboard.html.
